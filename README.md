# Site Vitrine de Restaurant

## Thème
Site vitrine pour un restaurant.

## Description
Ce projet est un site web vitrine responsive conçu pour présenter l'univers, la carte et les services d'un restaurant.
Il permet aux visiteurs de consulter les menus grâce à un filtrage interactif et d'effectuer une demande de réservation via un formulaire.
L'ensemble est développé sans framework, avec une approche mobile-first et un code conforme aux standards du web.

## Technologies utilisées
- HTML5 (sémantique et accessible)
- CSS3 (Flexbox, CSS Grid, variables CSS, responsive mobile-first)
- JavaScript vanilla (manipulation du DOM, événements, sans bibliothèque externe)
- Git & GitHub (gestion de version)
- Hébergement Vercel
